SISTEMA DE ASISTENCIAS

Problemática:
El primer problema es que todos nos registramos de manera manual la lista fisica propenso a errores
Dificultad para generar un reporte, consultar o perdida de la lista fisica 
Falta de orden en el momento de marcar asistencia, permitiéndoles a algunos no marcar respecto a la hora correcta a la que llegaron
Aglomeración de datos al momento de mandar el registro o mostrar al debido monitor(a)
Ineficiencia con las asistencias de los que trabajan vía remoto

Objetivos:
Crear un sistema que registre correctamente las asistencias, eliminando cualquier dificultad
Facilitar el registro de asistencias para el administrador y darle mejor acceso a un reporte correspondiente

Propuesta de solución: 

Desarrollo e implementación de un Sistema Web Centralizado de Control de Asistencias Multimodal (Presencial y Remoto), diseñado para automatizar el registro, garantizar la precisión de los horarios y simplificar la generación de reportes administrativos. 

desarrollar un sistema web que permita digitalizar el registro la consulta y la administracion
identificación rapida a cada persona mediante un ID que registra automáticamente la fecha y la hora  esto permite para presencial como remota 
Asistencia presencial:
Componentes del Sistema
1. Módulo Presencial (Estación Local)
Ubicación: Una terminal o computadora fija dentro de las instalaciones.
Mecanismo de marcado:
Interfaz web responsiva y optimizada para registro rápido (por ejemplo: ingreso de DNI/Código de practicante o escaneo de código QR personal desde una tarjeta o celular).
Sincronización de tiempo: La hora de registro es tomada automáticamente del servidor central, impidiendo que el usuario modifique la hora de llegada.
Control de flujo: Pantalla de confirmación visual inmediata para evitar aglomeraciones e inconvenientes al marcar.
2. Módulo Remoto (Acceso Web / Móvil desde Casa)
Mecanismo de marcado:
Inicio de sesión individual seguro con credenciales de practicante.
Botón directo para marcar "Inicio de Jornada" y "Fin de Jornada".
el responsable crea una sesión de asistencia que genera un codigo temporal 
el participante  inicia sesión con el codigo generado mas su codigo y registra asistencia como remota 
3. Panel Administrativo y Reportes
Dashboard en tiempo real: Muestra al administrador quiénes han marcado asistencia presencial y remota al instante.
Módulo de Reportes: Exportación automática de registros por rangos de fecha, estado (A tiempo, Tardanza, Falta) y modalidad (Presencial/Remoto) en formatos Excel y PDF.
Gestión de Usuarios: Creación y asignación de roles (Administrador, Practicante Presencial, Practicante Remoto).
Beneficios Directos frente a la Problemática
Eliminación del papel y errores humanos: Sustituye la lista física por una base de datos segura y centralizada.
Imposibilidad de alterar horas: El sistema asigna el timestamp (marca de tiempo) exacto del servidor en el momento de la interacción.
Control unificado: Permite gestionar en una sola plataforma tanto al personal que asiste a la oficina como al que trabaja desde casa.
Reportes instantáneos: El administrador obtiene consolidados de asistencia en pocos clics sin necesidad de digitar manualmente.
